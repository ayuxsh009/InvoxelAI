# UI Screenshot / Mockup Descriptions

1. Login Page:
- Centered card with email/password and CTA.
- Warm accent color for primary button.

2. Dashboard:
- Sidebar on left with 5 modules.
- Top summary cards: total invoices, taxable, GST, grand total.
- Bar chart for monthly CGST/SGST/IGST.

3. Upload Page:
- Large drag-and-drop area with icon, supported formats, progress percentage.
- Toast appears on success/failure.

4. Invoice Table:
- Search bar, export buttons, paginated rows.
- GST validation badges and modal detail view.

5. Chat Interface:
- Input query box and interpreted filter output.
- Matching invoice list with GST values.

6. Theme Modes:
- Light mode: soft cream + orange accents.
- Dark mode: deep slate + warm highlights.

7. Mobile View:
- Sidebar collapses into compact top section.
- Cards and table stack vertically.
